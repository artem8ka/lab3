# Лабораторная работа №3

## Каталог медиатеки

Пакет для хранения медиаматериалов, поиска по категории и части названия, сохранения и загрузки каталога в JSON.

### Установка

Требуется Python 3.12 или новее. Команды ниже предназначены для Windows PowerShell.

+ Открыть терминал в корневой папке проекта, где находится `pyproject.toml`.
+ Создать виртуальное окружение:

```powershell
py -m venv .venv
```

+ Активировать виртуальное окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

Если PowerShell запрещает запуск скрипта, разрешить выполнение для текущего окна терминала и повторить активацию:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

+ Установить зависимости:

```powershell
python -m pip install -e .
```

### Команды

```powershell
# Запустить все тесты
python -m pytest

# Проверить код с помощью Ruff
python -m ruff check .

# Запустить демонстрационный пример
python -m catalog
```

Демо добавляет два медиаматериала в каталог, сохраняет его в `demo_catalog.json`, загружает данные в новый каталог и выводит восстановленные материалы. JSON-файл создаётся в папке запуска.
